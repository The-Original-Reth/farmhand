# seed_data

Sample files for `python -m app.seed`. They aren't kept in the repository: put them in this folder yourself to seed a
fresh database. The seed expects these exact names:

- `MMMini_GreatWhiteShark_v01.stl`
- `MMMini_Frog_verticalEyes_v01.stl`
- `MMMini_Frog_horizontalEyes_Keychain_v01.stl`
- `VT_1190_-_prusa_slicer_-_MMMini_GreatWhiteShark_v01.3mf`
- `V2_BOG_-_Prusa_Slicer_-_MMMini_GreatWhiteShark_v01.3mf`
- `VT_1190_-_prusa_slicer_-_MMMini_Frog.3mf`

This README stays so the folder exists (the backend Dockerfile copies it into the image).
