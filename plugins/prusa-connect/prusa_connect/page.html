Prusa Connect

Farmhand's Prusa printers' status and prints from the farm's Prusa Connect server, instead of each printer's PrusaLink. Built on Prusa Connect by Prusa Research.

The Prusa Connect server

Printers

For each Prusa printer, choose which printer on Prusa Connect it is (a printer with the same name is chosen by itself). Then, in Farmhand, open the printer and set Status from in its PrusaLink section to this plugin. Prints are still sent to the printer's PrusaLink.
